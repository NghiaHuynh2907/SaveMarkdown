Đăng nhập

Nhập GitHub token của bạn để mở tài liệu trong .

Lấy token ở đâu?
  1. mời bạn vào repo (Settings → Collaborators). Bạn bấm chấp nhận lời mời trong email.
  2. Mở GitHub → tạo Fine-grained token.
  3. Resource owner: chọn .
  4. Repository access → Only select repositories → chọn .
  5. Permissions → Contents: Read and write. Bấm Generate token, copy và dán vào ô trên.

Không chọn được ở Resource owner hoặc không thấy repo trong danh sách? GitHub chưa cho token loại này truy cập repo của tài khoản khác. Khi đó tạo token classic (tick quyền repo, đặt hạn dùng) và dán vào ô trên.

Token chỉ lưu trong trình duyệt của bạn và chỉ gửi tới GitHub.
